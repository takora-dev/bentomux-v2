**Windows startup race fix — 2026-09-22**

- `src/preload/bentomux.ts`: retry initial `get_state` IPC up to four times with bounded backoff. WebView2 can dispatch first invoke while native startup is still settling; later commands remain unchanged.
- File `src/src/main.ts`, `src/src/views/sidebar.ts`, dan `src/src/views/terminal.ts` memiliki perubahan existing sebelum task ini; tidak disentuh.


Visible xterm canvases now refit and force-refresh after window focus/visibility changes. This covers macOS/WebView compositor cases where agent output remains live but text styling disappears until selection triggers repaint.

Sidebar terminal kini punya kontrol close per pane. Klik kiri tombol `×` menutup pane lewat flow `closeTerminalPane`; event dihentikan agar tidak ikut mengaktifkan atau memulai drag row.
