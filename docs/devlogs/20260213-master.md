## Ringkasan

Menambahkan drag-and-drop untuk mengubah urutan tab terminal/diff dan grouping visual berdasarkan workspace. Urutan tab sekarang dipersist ke `bentomux.json`, sehingga reorder tetap ada setelah quit dan buka ulang.

## Catatan

Workspace reorder sudah dipersist sebelumnya. Tab reorder sebelumnya hanya mengubah `ui.tabs` session-state; fix ini menghubungkannya ke persisted backend state.

Terminal kini memakai WebLinksAddon dengan Tauri opener callback. Hanya URL `http:` dan `https:` yang dibuka; scheme lain ditolak.

Sidebar terminal kini punya kontrol close per pane. Klik kiri tombol `×` menutup pane lewat flow `closeTerminalPane`; event dihentikan agar tidak ikut mengaktifkan atau memulai drag row.
